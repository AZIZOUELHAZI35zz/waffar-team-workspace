Build a private internal team management web application for my startup **WAFFAR**.

## 1. Goal

Create a simple, clean, modern internal workspace for a small startup team.

The application is NOT a public product and NOT a mobile application.

It is an internal web dashboard where team members can:

- See their own tasks
- See tasks assigned to other team members
- Create and assign tasks
- Update task status
- Track how much time they spend working
- See how much time other team members spent
- See the activity/progress of the team
- Know what each person is currently working on

The main objective is **team coordination and transparency**, not project-management complexity.

Keep the MVP simple.

# 8. Time Tracking

This is one of the most important features.

Every task should have a timer.

Example:

00:32:15

When the user clicks:

START TIMER

start recording work time.

When they click:

STOP TIMER

save the session in Supabase.

Do NOT rely only on the browser timer.

Store actual sessions in the database.

Create a table:

time_sessions

Fields:

- id
- task_id
- user_id
- started_at
- ended_at
- duration_seconds
- created_at

The application should calculate total time from saved sessions.

If the browser is refreshed while a timer is running, the application must recover the active timer from Supabase.

A user should not be able to have two active timers simultaneously.

# 15. Security

Enable Supabase RLS.

Authenticated users can:

- Read team members
- Read tasks
- Read activity
- Read time tracking
- Create tasks
- Update tasks
- Add comments
- Start/stop their own timers

Users should not be able to modify another user's time session.

The CEO should have elevated permissions for administration.

Do NOT expose Supabase service-role keys in frontend code.

Use only public Supabase environment variables in the client.
